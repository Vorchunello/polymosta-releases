# Polymosta

Learn a new language through the languages you already know. Windows, Linux and Android.

[Русский ниже](#polymosta-по-русски)

This repository only hosts downloads and public documents. It contains no source code.

## Download

Get the latest version from **[Releases](https://github.com/Vorchunello/polymosta-releases/releases)**:

| System | File |
| --- | --- |
| Windows, installer | `Polymosta.Setup.X.Y.Z.exe` |
| Windows, portable | `Polymosta.X.Y.Z.exe` |
| Linux | `Polymosta-X.Y.Z.AppImage` |
| Android | `Polymosta-X.Y.Z.apk` |

Offline dictionaries are in the [dicts](https://github.com/Vorchunello/polymosta-releases/releases/tag/dicts) release. The app downloads them for you in Settings → Offline.

Questions and bug reports: [Issues](https://github.com/Vorchunello/polymosta-releases/issues).

# Polymosta по-русски

Учи новый язык через языки, которые уже знаешь. Windows, Linux и Android.

В этом репозитории только файлы для скачивания и открытые документы, исходного кода здесь нет.

Последняя версия — в **[Releases](https://github.com/Vorchunello/polymosta-releases/releases)**: установщик и портативная версия для Windows, AppImage для Linux, APK для Android. Офлайн-словари приложение скачивает само: Настройки → Офлайн.

Вопросы и ошибки: [Issues](https://github.com/Vorchunello/polymosta-releases/issues).

Приложение закрытое и бесплатное: условия в [LICENSE](LICENSE), конфиденциальность в [PRIVACY.md](PRIVACY.md). Офлайн-словари собраны из английского Викисловаря через [kaikki.org](https://kaikki.org/) и доступны под [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
